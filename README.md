# Ashifa sharin Y — Portfolio

A responsive personal portfolio built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Edit the content

Update `src/data/portfolio.ts` to change the introduction, educational qualifications, focus areas, toolkit, projects, hackathons, achievements, certificates, hobbies, languages, contact details, and social links.

To add a portrait, place the image at `public/ashifa-profile.jpg` and set `profilePhoto` to `"/ashifa-profile.jpg"` in `src/data/portfolio.ts`. The framed portrait illustration is shown until a photo path is configured.

## Verify

```bash
npm run typecheck
npm run build
```
